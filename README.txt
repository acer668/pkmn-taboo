Pokemon Taboo
==============
Open index.html in a browser. The app loads Pokemon data from PokeAPI, so an internet connection is required.

Features:
- Generations 1-9
- Easy (4), Medium (6), Hard (6) taboo words
- Random Pokemon selection
- Rules popup
- 3-minute timer
- Red taboo button: +2 penalty
- Game over state and penalty display
- Next Pokemon during an active round

Note: PokeAPI supplies the Pokemon roster and supporting data. A small set of iconic Pokemon has hand-written taboo lists; the rest use automatically selected type/ability/move/species-category clues while avoiding generation/region terms.
